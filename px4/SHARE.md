# 이슈사항 & 특이사항
1. 서버 부하량
- CPU 사용량이 어마무시함. 상시 1Core, 많이 사용할 땐 2Core 까지 사용함.
- px4의 설정값(해상도 등)을 조절하여 CPU 사용량을 일부 최적화할 수 있으나, 그래도 많긴함.
- 메모리 사용량은 약 2GB 정도로 보여 적정치로 판단. 
- 이거 도커 

2. px4 + Gabezo(Headless) 
해당 조합으로 구현함. Gabezo GUI, QGC는 안쓰기로 판단함. 그러나, 이것이 GUI 환경에서
어떤 기능들을 제공하는지, 어떻게 동작하는지는 스크린샷으로 문서화해놓으면 좋을듯.

3. API 명세서
UAV Agent가 어떤 데이터를 제공하는지 다른 팀원들이 알아야 이 프로젝트의 맥락을 잡기 편해짐.
이에 따라, Mock Data라도 생성하여 REST API로 조회할 수 있도록 만들었음. 
Mock Server 호출, 실제 Server(px4) 호출 두 버전 준비해놓았음.

4. 작업 범위, 요구 사항 범위 ( 좀 더 상세하게, )
다음 회의때 가장 중요한 내용이라고 판단됨. 내용 범위가 추상적이고 너무 많아서 각자 판단대로 하면 작업기간도 늘어나고, 이상해질 수 있어서 주기적으로 명세서 비교해가면서 어떤 데이터 필요한지, 어떤 데이터 줄지 검토하면 좋을듯.

일단 내가 필요한 데이터
4-1. 고도 필드 추가
target_lat, target_lon 옆에 target_alt_m 대충 이런 필드명으로 고도 필드 추가해야 될듯. 드론한테 어디로 가라고 할 때 위도,경도만 오면 높이를 모름. 고도까지 알아야 됨. Dron한테 명령어 보낼 때 goto(위도, 경도, 높이) 형태로 보내야해서 필요함.

4-2. 위경도 수치 변환 필요
 cell_id: "50_50" 일단 이렇게 오면, 드론 명령어 goto(위도, 경도, 높이)에서 어떤 값이 위도,경도,높이 인지 모름. 그래서 38.0425, 128.2541 이런 위도, 경도 값이 필요함. 

4-3. 풍속.. 얘의 원천지를 잘 모르겠음.
풍속은 환경모델(EnvironmentState.wind_speed)에 구현 된 것으로 보임. 풍속을 드론한테 임무 줄 때 풍속도 같이 실어주면 될 거 같음. 근데 이게 환경모델에서 주는건지, Task 부여할 때 첫 요청에서 주는건지 잘 모르겠음. 그리고 얘는 풍속에 따라 드론이 올 수 있는지 여부를 체크하는데 사용하는게 맞나? 

5. 드론 개수 여러 개 일때
드론은 한 대만 띄우는게 아니라, 여러 대 띄울거라고 생각함. 그럴 경우, 프로세스별로 여러 개 띄우는거랑, 서버 별로 여러 개 띄우는거랑 있는데 서버 별로 격리해서 띄울 예정임. 왜냐면 프로세스별로 띄울 경우 서버 부하견디기도 힘들고, udp 14550 포트 경합일어나서 설정바꿔야하는 번거로움이 발생함. 실무 기준으로도 서버 별로 격리하는게 맞아서 드론 개수만큼, 서버 개수를 증가시키는게 맞다고 생각함. 만약 그게 좀 부담스럽다면, 지금 서버에서 Mock Server 여러 대 띄어서 진행해야할듯.

## 프로젝트 이해를 돕기 위해 기록 (끄적끄적)


#### 일단 가장 중요한거, 과연 드론 가용여부를 어떤 기준으로 판단할지가 가장 중요함. 
1단계: 기체 상태 (계산 없이 즉시 판단)
기준	왜 필요한가
비상모드 작동 중?	드론이 이미 문제를 감지한 상태. 명령 받을 상황이 아님
GPS·센서 정상?	위치를 모르면 어디로 갈지도 모름
통신 끊김?	명령을 보내도 안 들림
다른 일 하는 중?	한 번에 하나만
그 센서 달려있나?	열화상 요청했는데 카메라만 있으면 못 함
바람이 한계 넘나?	10m/s 이상이면 못 뜸
이 6개는 숫자 계산 없이 O/X로 끝납니다. 하나라도 걸리면 바로 거절.

2단계: 배터리 (거리 계산 후)
거리 → 가는 시간
높이차 → 올라가는 시간
합 × 2(왕복) + 관측 체류시간 = 총 소요
총 소요 × 소모율 = 필요 배터리

그리고 두 단계로 나눠 판단:

배터리가 아예 모자람 → 거절
갈 수는 있는데 돌아오면 20% 미만 → 역제안 ("관측 시간 줄이면 가능")

3단계: 시간 (기한이 있을 때만)
기한이 이미 지남 → 거절
도착이 기한보다 늦음 → 역제안 ("이 시각에 도착 가능한데 괜찮나?")
마지막: 바람 주의
한계(10m/s)는 안 넘었지만 8m/s 이상이면 → 역제안 ("고도 낮춰라")
