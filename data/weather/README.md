# 2019-04-04 인제 산불 재현용 기상 관측 자료

| 파일 | 내용 |
|---|---|
| `kma_asos_hourly_20190404_20190405.csv` | 기상청 ASOS 시간자료. 인제(211)·속초(90)·홍천(212)·대관령(100), 2019-04-04 00시 ~ 04-05 23시, 지점당 48건 |

- 출처: 공공데이터포털 「기상청_지상(종관, ASOS) 시간자료 조회서비스」 (https://www.data.go.kr/data/15057210/openapi.do). 출처 표시 조건으로 이용.
- 수집: `tools/collect_kma_asos_hourly.py` (인증키 `DATA_GO_KR_SERVICE_KEY`, 값은 저장소에 두지 않음)
- 시각 `tm` 은 한국 표준시(KST). 주요 열: `ta` 기온(℃), `ws` 풍속(m/s), `wd` 풍향(16방위 degree, 불어오는 쪽), `hm` 습도(%), `rn` 강수(mm). `*Qcflg` 는 기상청 품질 플래그.
- 시간자료의 풍속은 정시 기준 평균값이며 순간 돌풍은 없다.

## 사용 원칙 (총괄 오케스트레이터)
- 시뮬레이션 시계 기준으로 **그 시각까지 관측된 값만** 총괄에 전달한다 (미래 값 선공개 금지).
- 관측소 지점값으로만 쓰고, 총괄이 산 전체로 임의 보간하지 않는다. 공간 분포는 환경 모델 몫이다.
- 결측은 결측으로 둔다.
- 환경팀도 같은 자료로 "진짜 세계" 바람을 만들어야 두 세계가 서로 맞는다 (계약 필요).
